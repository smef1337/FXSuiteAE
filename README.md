# FX Suite — After Effects Extension
**FX Suite** is an all-in-one productivity panel for Adobe After Effects. It combines an accurate Flow-style curve editor, essential one-click quick tools, an `.ffx` preset browser, and audio beat detection into a sleek, customizable interface.

## ✨ Features
- 📈 **Flow-Style Curve Editor:**
  - 28 built-in standard easing presets (Robert Penner curves) + save/delete custom curves.
  - Full support for overshoot curves, true linear interpolation, and reading/applying transition eases (`In`, `Both`, `Out`).
- ⚡ **Quick Tools:**
  - One-click shortcuts for Linked Null, Camera, Adjustment Layer, Solid, Null, Precomp, Freeze Frame, Center Anchor Point, Fit to Comp, Reverse, and Fill.
  - Interactive 9-point anchor point grid.
  - Fully customizable tool order and visibility in settings.
- 📁 **Preset Effects Library:**
  - Browse and search your `.ffx` presets from any chosen folder.
  - Apply with one click: either as an auto-trimmed adjustment layer above selected clips or directly onto the selected layer.
- 🎵 **BeatMarker:**
  - Automatic audio transient analysis to generate rhythm and beat markers.
- 🎨 **Custom Themes & Cross-Platform:**
  - Full color customization (accent, background, inputs).
  - Cross-platform settings persistence in `~/Documents/FXPluginSettings` across both Windows and macOS.

## 🚀 Installation
### 🪟 Windows
1. Close Adobe After Effects.
2. Right-click **`Install_FXSuite.bat`** and select **Run as administrator**.
3. Follow the on-screen prompts and relaunch After Effects.
4. Open the panel via **Window > Extensions > FX Suite**.
### 🍎 macOS
1. Close Adobe After Effects.
2. Open Terminal in the project folder and run:
   ```bash
   chmod +x Install_FXSuite.sh
   ./Install_FXSuite.sh
3. Relaunch After Effects and open the panel via Window > Extensions > FX Suite.
